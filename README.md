# korek

*korek* is Taglish for "correct": define types once, get them right in every language.

You declare types (enums, structs, unions) and typed keys (named settings
with defaults, docs and constraints) in KDL v2, and korek emits Rust (serde),
Protobuf, TypeScript Zod and bare TypeScript from them.

Work in progress; see the `v1` branch.
