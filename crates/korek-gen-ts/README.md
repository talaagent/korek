The TypeScript generator of [korek](https://github.com/talaagent/korek): bare `type` / `interface`
declarations with no runtime dependency, rules as JSDoc tags, a `Keys`
interface and key defaults.

Part of [korek](https://github.com/talaagent/korek): schema files in, Rust, Protobuf, Zod, TypeScript and JSON Schema out.
