The markdown docs generator of [korek](https://github.com/talaagent/korek): a reference of every type,
field, enum variant, settings key and service, with validation rules in
words, units humanized and extra columns from extension metadata.

Part of [korek](https://github.com/talaagent/korek): schema files in, Rust, Protobuf, Zod, TypeScript and JSON Schema out.
