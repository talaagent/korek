The small runtime that Rust generated by [korek](https://github.com/talaagent/korek) depends on: the
`Validate` trait, validation errors with field paths, string format checks
(email, URL, UUID, IP, ...), the base64 serde adapter for `bytes`,
`timestamp`/`duration` parsing and typed settings keys (`Key<T>`).
Validation does not allocate when the value is valid.

Features: `regex` (default; `pattern` rules and the emoji format) and `json`
(default; `json` fields as `serde_json::Value`).

Part of [korek](https://github.com/talaagent/korek): schema files in, Rust, Protobuf, Zod, TypeScript and JSON Schema out.
